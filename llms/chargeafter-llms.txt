## API Reference
- [Overview](https://docs.chargeafter.com/reference/api-overview.md)
- [API Environments](https://docs.chargeafter.com/reference/api-environments.md)
- [Authentication](https://docs.chargeafter.com/reference/authentication.md)
- [API Changes Guidelines](https://docs.chargeafter.com/reference/api-changes-guidelines.md)
- [Create a new session](https://docs.chargeafter.com/reference/post_v3-session-1.md): Creates a session with an optional cart, consumer and checkout details.
- [Get interactive token](https://docs.chargeafter.com/reference/get_v2-checkout-applications-applicationid-token.md): Returns a time-limited interactive session token to resume the Checkout flow for an account associated with the application.
- [Get lender accounts and offers](https://docs.chargeafter.com/reference/get_v3-session-accounts-1.md)
- [Get accounts with offers for consumer](https://docs.chargeafter.com/reference/post_v2-checkout-accounts.md): Looks up an existing account and returns relevant offers. If there is no existing account, this creates a new account and returns relevant offers.
- [Get accounts with offers with existing applicationId](https://docs.chargeafter.com/reference/post_v2-checkout-applications-applicationid-accounts.md): Looks up an existing account and returns relevant offers.
- [Create new charge with accountToken](https://docs.chargeafter.com/reference/post_v2-accounts-charge.md): Creates a new charge from an existing approved account with an accountToken.
- [Get status of an application](https://docs.chargeafter.com/reference/get_v2-checkout-applications-applicationid-status.md)
- [Create a new Charge](https://docs.chargeafter.com/reference/post_v2-post-sale-charges.md): Initiates a new charge transaction, allowing you to securely process payments from customers. This action is typically used to bill for products or services.
- [Get details of a Charge](https://docs.chargeafter.com/reference/charges-get-details.md): Fetching updated information of an existing Charge
- [Update a Charge](https://docs.chargeafter.com/reference/charges-update.md)
- [Update delivery data](https://docs.chargeafter.com/reference/charges-update-data.md): Update delivery data for items in an existing Charge
- [Refund a Charge](https://docs.chargeafter.com/reference/charges-refund.md): Process a refund for a previously settled amount. This action facilitates the return of funds to the customer for various reasons, such as returned goods or canceled services.
- [Settle a Charge](https://docs.chargeafter.com/reference/charges-settle.md): Complete a payment transaction by settling a charge. This action confirms the secure transfer of funds according to the authorized terms.
- [Void a Charge](https://docs.chargeafter.com/reference/charges-void.md): Cancel and invalidate an authorized charge before it is settled. This action prevents the charge from being completed or appearing on the customer's statement. Use voiding for transactions that need to be canceled early in the process.
- [Consumer Management](https://docs.chargeafter.com/reference/consumer-management-1.md)
- [Get consumer details](https://docs.chargeafter.com/reference/get_v2-consumers-consumerid-1.md): Returns consumer details
- [Get accounts by consumerId](https://docs.chargeafter.com/reference/get_v2-consumers-consumerid-accounts.md): Lookup existing accounts by consumerId
- [Get accounts and account token](https://docs.chargeafter.com/reference/post_v2-consumers-consumer-details.md): Combines account lookup and account token creation for approved accounts
- [GET funding report](https://docs.chargeafter.com/reference/get_v2-post-sale-fundings-report-1.md): Return funding records based on supplied filters.
- [Omni-Link](https://docs.chargeafter.com/reference/links.md)
- [Generate consumer application link](https://docs.chargeafter.com/reference/post_v2-omni-link-consumer-application.md): This endpoint generates a unique URL for a given consumer context that can be used to launch ChargeAfter's Apply experience.
- [Generate consumer checkout link](https://docs.chargeafter.com/reference/post_v2-omni-link-consumer-checkout.md): This endpoint generates a unique URL for a given consumer context that can be used to launch ChargeAfter's Checkout experience.
- [Get link data](https://docs.chargeafter.com/reference/get_v2-omni-link-consumer-linkid.md): Enables retrieval of link data for the consumer-associated context.
- [Event Notifications](https://docs.chargeafter.com/reference/merchants-notifications.md): Descriptions and payloads of webhooks available for subscription via Operate
